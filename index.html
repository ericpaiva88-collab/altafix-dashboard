Guia Rápido — Alta Fix

🎯 Cockpit (O que fazer agora?)Abra o Cockpit para ver os KPIs vitais (Meta, Falta, Precisa/Dia). O bloco "Atenção Agora" mostra os 5 maiores problemas do dia.
📱 Relatório MatinalClique no botão preto no topo do Cockpit para gerar um texto pronto com a situação do mês e as prioridades. O texto é copiado automaticamente para você colar no WhatsApp do time.
🎯 Agenda (Modo Foco)Na aba Agenda, use o "Modo Foco" para ver um cliente por vez. O sistema já filtra quem precisa de ligação (retornos atrasados ou clientes no ciclo de recompra).
👥 Equipe (Ficha 1:1)Clique no card do vendedor para ver o histórico dele. Use o "Diário de Bordo" para anotar o que foi combinado na reunião.
⚙️ ImportaçõesAntes de importar, selecione a Filial no topo. Arraste as planilhas para a aba Configurações. O botão "Salvar e Sincronizar" envia os dados para a nuvem.
